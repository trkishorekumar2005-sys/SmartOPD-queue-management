# SmartOPD frontend

React + Vite single-page app for patients, staff and the waiting-room display.

See the main [README](../README.md) for setup, architecture and API details.

```
npm install
npm run dev      # development server (http://localhost:5173)
npm run build    # production build into dist/
npm run lint     # oxlint
```

The API address is set in `src/services/api.js` (`http://localhost:5000/api`).
